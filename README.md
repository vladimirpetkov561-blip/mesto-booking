# Mesto Booking

Full-stack booking application built as a portfolio project.

## Overview

Mesto Booking is a full-stack web application for browsing and booking accommodation.

The project demonstrates frontend and backend development, REST API integration, authentication, database work and Docker-based development.

## Features

- Browse available places
- View detailed information about each place
- User registration
- User login
- JWT authentication
- Protected API endpoints
- Create bookings
- Prevent duplicate bookings
- View personal bookings
- Logout
- Responsive interface
- Local accommodation images

## Tech Stack

### Frontend
- React

- JavaScript
- CSS

### Backend
- Python
- FastAPI

### Database
- PostgreSQL
